Desarrollo de la Fase 4 - Prácticas simuladas

## Módulo de clientes

En `clientes.py` implementé las clases `Cliente` y `GestorClientes` para registrar, buscar y listar clientes. El módulo valida los datos y evita que se registre dos veces el mismo identificador.

Probé el registro, la búsqueda y el listado desde `main.py`. También comprobé que el programa vuelve al menú después de intentar registrar un ID duplicado o buscar un cliente inexistente. Ambas advertencias quedaron guardadas en `registros/sistema.log`.
