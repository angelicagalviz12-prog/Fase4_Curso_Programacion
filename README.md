# Sistema Integral de Gestión de Clientes, Servicios y Reservas

Fase 4 – Prácticas simuladas
Empresa: Software FJ  
Lenguaje: Python

## Descripción del proyecto

Este proyecto consiste en desarrollar un sistema para gestionar clientes, servicios y reservas de la empresa Software FJ, aplicando los principios de programación orientada a objetos en Python.

El sistema permite registrar, buscar y listar clientes; administrar servicios de salas, equipos y asesorías; y crear, consultar, confirmar y cancelar reservas.

## Estructura del proyecto

El proyecto está organizado en los siguientes archivos:

- **main.py:** contiene el menú principal y coordina las funcionalidades del sistema.
- **entidades.py:** define la clase abstracta `Entidad`.
- **clientes.py:** permite registrar, buscar y listar clientes.
- **servicios.py:** gestiona los servicios de salas, equipos y asesorías.
- **reservas.py:** permite crear, consultar, confirmar y cancelar reservas.
- **excepciones.py:** contiene las excepciones personalizadas del sistema.
- **logs.py:** configura el registro de eventos y errores.

## Características principales

- Programación orientada a objetos: herencia, encapsulamiento, abstracción y polimorfismo.
- Validación de datos y manejo de excepciones.
- Control de disponibilidad de servicios.
- Gestión de reservas y cálculo de costos.
- Registro de eventos y errores mediante `logging`.
- Almacenamiento de información en listas en memoria.

## Herramientas utilizadas

- Python.
- Visual Studio Code.
- GitHub.

## Ejecución del programa

Para ejecutar el sistema, abre una terminal en la carpeta del proyecto y ejecuta el siguiente comando:

`python main.py`
